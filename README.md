# LLM Neuron Analysis

LLMの内部ニューロンをAblate/Fire操作し、推論に影響を与える「制御ニューロン」を特定する実験。

## 概要

Mistral / Qwen2.5-3B に対し、特定のニューロンを層単位で操作することで、モデルの推論挙動がどう変化するかを計測した。

## 主な発見

| ニューロン | 役割 | 消した時の症状 |
|-----------|------|--------------|
| #2070 | 独裁的な門番（ルール制御） | 指示を無視してシステムタグが漏洩・崩壊 |
| #1935 | 算数脳（数値演算） | 計算ができなくなり、目の前の数字を答えにする |
| #3398 | 社会性のフィルター（文章終端） | 文章の終わりが汚くなり、数式が剥き出しになる |
| #2661 | 論理の整理担当 | 説明がくどくなり、独自タグが漏れ出す |

- **崩壊閾値**: #2070 の critical bias ≈ 0.16〜0.18
- **L0-1が緩衝地帯**: 超下位層へのバイアスが崩壊を引き起こす主因
- **非対称な感度**: 抑制には鈍感、過励起には敏感（制御ニューロンの特徴）

## 実験手法

```python
# ニューロンをAblate（無効化）する例
config = [{"idx": 2070, "mode": "ablate", "layers": list(range(32))}]

# ニューロンをFire（強制発火）する例
config = [{"idx": 1935, "mode": "fire", "value": 0.2, "layers": [10, 11, 12]}]

with LayerSpecificManipulator(model, config):
    output = model.generate(...)
```
